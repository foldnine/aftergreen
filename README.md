# AfterGreen

**Green isn't proof.** Verify what actually happened.

AfterGreen is an experimental, open-source outcome verification engine for automations, built by FoldNine.

> Status: early development. The first milestone is a local Go CLI and deterministic sample evidence; live n8n/PostgreSQL adapters are not implemented yet.

Development takes place through reviewable pull requests. The first implementation is being prepared in a draft PR.
