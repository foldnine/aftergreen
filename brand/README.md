Keep this directory as the source of truth. In `foldnine/aftergreen-action`, reference a stable revision of these assets or copy them with attribution to this source rather than re-inventing another logo.

**Review note:** the source SVG paths and palette match the approved design. Text lockups are SVG text rather than font-outlined vector paths. The mockup that inspired the brand is not product documentation.
